# youtube-dq-pipeline

Ежедневный пайплайн, который забирает статистику видео YouTube-канала, загружает её в PostgreSQL и проверяет качество данных. Оркестрирует всё Apache Airflow, стенд поднимается в Docker, тесты запускаются в GitHub Actions.

> **Статус:** проект в активной переработке. Ниже описано текущее состояние и план улучшений.

## Происхождение

Проект основан на [raivskal/YT_ELT](https://github.com/raivskal/YT_ELT). Из оригинала взят каркас: загрузка из YouTube Data API, Docker Compose со стендом Airflow, проверки Soda и CI на GitHub Actions. Всё, что изменено после этого, видно в истории коммитов этого репозитория.

## Что делает пайплайн

![Архитектура](images/architecture.png)

Сейчас пайплайн состоит из трёх DAG, каждый из которых запускает следующий:

| DAG | Что делает |
|---|---|
| `produce_json` | Раз в сутки получает список видео канала и их статистику из YouTube Data API v3, сохраняет в `data/YT_data_<дата>.json` |
| `update_db` | Загружает JSON в схему `staging`, затем переносит данные в схему `core` с преобразованиями |
| `data_quality` | Запускает проверки Soda на обеих схемах |

Для каждого видео собираются: ID, название, дата публикации, длительность, просмотры, лайки и комментарии. При переносе в `core` длительность переводится из формата ISO 8601 (`PT1M30S`) в тип `TIME`, а видео делятся на `Shorts` (до 60 секунд) и `Normal`.

## Проверки качества

Сейчас реализованы четыре проверки (`include/soda/checks.yml`):

- нет пустых `Video_ID`;
- нет дублей `Video_ID`;
- лайков не больше, чем просмотров;
- комментариев не больше, чем просмотров.

## Структура репозитория

```
youtube-dq-pipeline/
├── .github/workflows/      # CI: сборка образа, тесты, прогон DAG
├── dags/
│   ├── main.py             # определение трёх DAG
│   ├── api/                # клиент YouTube Data API
│   ├── datawarehouse/      # загрузка в staging и core
│   └── dataquality/        # запуск проверок Soda
├── include/soda/           # конфигурация и проверки Soda
├── docker/postgres/        # создание баз при старте Postgres
├── tests/                  # юнит- и интеграционные тесты
├── docker-compose.yaml
└── dockerfile
```

## Запуск

Раздел будет дописан после первого запуска стенда. Понадобятся:

- Docker и Docker Compose;
- ключ YouTube Data API v3 (бесплатно в Google Cloud Console);
- файл `.env` с параметрами баз данных, Airflow и API. Секреты в репозиторий не попадают.
